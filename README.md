## 🧠From Fundamentals to Defense: My Azure Cloud Security Learning Map

A structured breakdown of key security domains in Azure, aligned with best practices and real-world scenarios.

---

### 🔐 Identity & Access Control

> 🔑 Secure access starts with strong identity boundaries.

- **RBAC** – Role-Based Access Control for scoped permissions
  
  [🔍 Explore RBAC in depth →](https://github.com/Mubaarak1-git/secure-azure-foundations/tree/main/Code/identity-access-control)
- **JIT Access** – Just-In-Time elevation to reduce attack surface  
- **PIM** – Privileged Identity Management for sensitive roles  
- **Conditional Access** – Policy-based access enforcement

### 🧊 Data Protection

> 🧬 Safeguarding data at rest, in transit, and in use.

- **Encryption** – End-to-end protection for storage and traffic  
- **Azure Key Vault** – Centralized secrets and key management  
- **OAuth & API Tokens** – Secure authentication for services

📌 *Coming soon*: Key Vault integration with Azure Functions

### 🌐 Network Security

> 🌐 Defend your perimeter with layered controls.

- **NSGs & ASGs** – Network and application-level segmentation  
- **Private Endpoints** – Secure access to PaaS services  
- **Zero Trust Architecture** – Assume breach, verify explicitly

📌 *Coming soon*: NSG rule simulation and Zero Trust diagram

### 🧱 Infrastructure Hardening

> 🧰 Build secure-by-default environments.

- **Secure VM Configs** – Hardened OS images and settings  
- **Patch Management** – Update strategy for VMs and containers  
- **Least Privilege** – Scoped access for automation and scripts

### 📈 Monitoring & Threat Detection

> 📡 Visibility is your first line of defense.

- **Azure Defender** – Threat protection for workloads  
- **Azure Sentinel** – SIEM for intelligent detection  
- **Activity Logs** – Audit trails and diagnostic hooks

> 🧪 Validate posture and align with standards.

- **Static Analysis** – Tools like `tfsec`, `checkov` for IaC scanning  
- **Azure Policy** – Enforce guardrails across subscriptions  
- **Compliance Mapping** – ISO, NIST, CIS alignment
